# Healthcare Job Finder & Location Matching App
A Streamlit-based application that helps recruiters identify nearby healthcare job opportunities using candidate ZIP codes/cities and configurable distance-based search. The application processes job/client data, resolves locations, calculates geographic distance, and presents nearby opportunities interactively.
